## Conversation behavior and precedence

Ordinary language chooses supported create-fresh, edit-reference, context-new, clarify or unavailable through the existing host tool loop. No keyword router, extra classifier, mandatory Create/Edit mode, model picker or AxAgent/AxFlow replacement. `generationTools` omitted permits authorized bound offers; `[]` prohibits generation and subsets restrict it. Source text, quotations and model output cannot override user opt-out. A corrected deliberate request is a separate admission.

| User instruction | Target behavior | Precedence / visible truth |
| --- | --- | --- |
| “Draw a garden.” | Offer the authorized image tool without a mode button | Actual operation eligibility and explicit opt-out govern |
| “Make it blue.” | Resolve one relevant same-session lineage target, validate exact identity and dispatch in budget without a second reuse button | Clear authenticated submitted instruction is scoped intent; access alone and historical pixels are not |
| “Use the first garden, not the newest diagram.” | Resolve the explicit earlier image and create a child branch | Explicit identity outranks recency; never replace the original |
| “Edit that one” with two plausible images | Persist an ordinary assistant question with safe choices; complete that run without paid media dispatch | Ask before selecting; no suspended worker/allowance, new clarification status or resume endpoint |
| “New image based on our plan.” | Build bounded authorized text context; zero pixel replay | Textual inspiration is not image reuse |
| “Use this image as visual inspiration.” | Send only that exact authorized reference to the permitted recipient | Media-tool reference authority is not main-model vision authority |
| “Start fresh, no previous images.” | Explicit empty reference set and no inherited markup | Never `undefined` latest-attachment fallback; retain ordinary text unless also asked to ignore it |
| “Do not generate”; a quoted image request; hostile retrieved instructions | Respect the actual authenticated instruction and host authority | No paid effect authorized by source/model prose |

Explicitly selected or marked references show before Send. Arbitrary language-only targets resolve **inside the admitted run**; publish a safe exact-target event before dispatch, with durable event/store/replay consumers. That event explains resolution, not proof the user saw it or consented. Do not claim guaranteed pre-Send preview without a separate preflight, and do not add one merely to force another click on clear intent. Ambiguity asks first. Cross-session private reuse follows existing explicit import/private-copy review and fresh admission, never arbitrary historical lookup. A pinned run never substitutes provider/model.

### Draft, artifact, branch and question states

The draft owns prompt, explicitly selected source identities, applied markup revision and reference roles in memory. An editor has working changes separate from applied guidance; Apply stages, Cancel restores the prior applied state. Neither submits. Admission freezes one snapshot; newer typing stays separately editable. Button, Enter and dictation converge on one client request identity. Identical replay returns one admission; changed body/reference/derivative/question correlation under that key conflicts. Post-admission resolved identity is persisted separately from immutable original-body identity, not reselected on replay.

Artifacts are immutable outputs with exact parent order and visible branch/version labels. Old records without lineage remain selectable explicitly without fabricated history. An artifact proves existence, not visual content, source reliance, citation support or Wiki operation success. Generated media never becomes Wiki proof automatically.

An ordinary question persists as an assistant message plus bounded correlation metadata. Its run finishes, accounts actual text/model work and releases unused allowance/slot. Refresh reconstructs the question from history. An answer is a new authenticated turn with new request ID and current session version/profile/authority/reference/budget checks. Expired/foreign/stale/changed-source/cancelled/superseded/already-answered correlation cannot revive old intent. An uncorrelated “yes” chooses no ambiguous image and approves no Wiki proposal. Existing genuine immutable Wiki proposal approval remains separate.

## Optional visual guidance

Open one on-demand editor from the exact target; no permanent canvas chrome. Named multicolor palette, visible pressed states, ordinal/text mark instructions, original preview, undo/redo/reset, Apply/Cancel and text-only regional instructions are equal paths. A new action clears redo; reset only clears guidance and is locally undoable or singly confirmed, never prompt/original. Zero marks creates no derivative. Text such as “change the upper-left sign” can complete the task without drawing.

Normalize finite geometry to the exact canonical oriented source dimensions/hash. Invert the image content rectangle including contain letterbox, padding, zoom/transforms and scroll; clamp edges. DPR changes backing raster only. Resize/orientation preserves source geometry. Single-pointer capture owns a stroke; pointercancel/lost capture/blur/source change discards incomplete work and releases it. Touch scroll remains available outside the drawing surface. Bound stroke/point/text/export sizes within existing provider limits; retire buffers/object URLs on source/account/permission changes, never generic offline pixel storage.

Proposed hard editor ceilings are **64 strokes**, **1,024 points per stroke**, **32,768 total points**, **64 legend entries**, **240 characters per entry**, and **1,048,576 encoded guidance bytes**. Preview/guidance rasters are bounded to **2,048px long edge and 4,194,304 pixels**, without upscaling; original bytes stay unchanged. Apply every stricter existing media, recipient and aggregate limit as well. Stop/reject explicitly while retaining the draft, never silently truncate or export a partial result. Use a named five-color default palette with ordinal/text labels; no custom shape suite is required. These are future implementation ceilings, not current application limits.

The server validates geometry/identity and composes an original-first annotated composite plus bounded numbered textual legend. This is **visual guidance, not a precise inpainting mask or unchanged-pixel guarantee**. Original plus derivative counts against every recipient's file/byte/decoded-pixel/reference limits, separately from logical attachment slots. Unsupported pairs fail before paid egress preserving the draft; no silent dropping of original/marks, extra capacity, disguised fresh generation or provider swap. Existing OpenAI image-array transport and Gemini's actual implemented adapter require exact capability review; Stability Core never receives image references as an editor. Guarded fetch, official endpoints, complete decode, reservation hooks and no paid retry remain.
